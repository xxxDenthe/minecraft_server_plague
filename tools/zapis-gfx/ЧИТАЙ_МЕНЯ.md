# Графика записей архивов

Три генератора, которыми нарисовано всё, что видно в записи. Держим
исходники, а не только PNG: править пиксели руками в 256×256 бумаге
с дизерингом невозможно, а подкрутить тон одной строкой — легко.

```
python font.py    -> tainopis.png          знаки тайнописи, 128×48
python gui.py     -> (через сборку ниже)   разворот и стрелки
python items.py   -> zapis_*.png           три вида записи, 16×16
```

Собрать всё и разложить по местам:

```
python сборка.py
```

Куда что ложится:

```
plaguecore/src/main/resources/assets/
  minecraft/textures/gui/book.png                 разворот (перекрывает ваниль)
  minecraft/textures/gui/sprites/widget/page_*.png  чернильные уголки
  plaguecore/textures/font/tainopis.png           знаки тайнописи
  plaguecore/textures/item/archive_record_*.png   бумаги, тетрадь, журнал
```

Правила, которые нельзя нарушать при правке:

- **Геометрия разворота жёсткая.** Экран книги блитит область 192×192
  и кладёт текст в x 36..150, y 30..158, а номер листа прижимает вправо
  к x=148, y=16. Бумага обязана накрывать эти прямоугольники с полями.
- **Плавных переходов быть не должно** — только дизеринг по четырём
  тонам: курс проекта на пиксельную приглушённую графику.
- **Знаки тайнописи белые с альфой.** Minecraft красит шрифт цветом
  текста, поэтому белый лист даёт чёрные чернила, а полупрозрачные
  пиксели — выцветшие концы штрихов.
- **Сетка шрифта.** Лист 128×48 = 16×6 ячеек по 8×8. Строки в
  `assets/plaguecore/font/sleepless.json` должны делить картинку нацело,
  иначе Minecraft молча не разберёт шрифт.
