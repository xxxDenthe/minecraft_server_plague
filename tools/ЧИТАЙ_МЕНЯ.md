# Целые здания из модов -> схематики для Axiom

Моды вроде Dungeons and Taverns не хранят готовых домов. Дом собирается
из комнат прямо в игре. Поэтому порядок такой: игра один раз строит все
дома в пустом мире, а скрипт вынимает их оттуда готовыми.

На выходе — `.schem`, которые открывает Axiom (`File → Import Schematic`).
Дальше из них делаются блюпринты: призрак под курсором, поворот, отмена.

## Что поставить заранее

- Minecraft 1.21.1 с тем же набором модов
- **Python 3** — https://www.python.org/downloads/
  При установке **обязательно** галочка «Add Python to PATH»
- Больше ничего. Никаких библиотек ставить не надо.

Распакуй архив в любую папку. Внутри лежит **`RUN.bat`** —
он делает всю работу с файлами за тебя, вручную ничего копировать не нужно.

---

## Шаг 1. Создать мир

В Minecraft: Одиночная игра → Создать мир.

- Тип мира: **Суперплоский** (пресет не трогать)
- Режим: **Творческий**
- **Читы: включены**
- В настройках графики дальность прорисовки: **24 чанка или больше**

Последнее важно. Иначе дальние здания попадут в непрогруженные чанки
и игра откажется их ставить.

Создал мир — выйди из него в главное меню.

## Шаг 2. Положить датапак

Двойной клик по **`RUN.bat`**.

Он спросит **путь к папке игры**. Это та папка, внутри которой лежат
`mods`, `config` и `saves`.

Самый простой способ: открой её в проводнике, схвати мышкой саму папку
и перетащи в чёрное окно — путь вставится сам. Потом Enter.

Если перетащишь `saves`, `mods` или сам мир — тоже поймёт.

Дальше выбери пункт:

```
1) Положить датапак в мир
```

и свой мир из списка. Всё, датапак на месте. Закрой окно.

## Шаг 3. Расставить здания

Зайди в мир и напиши:

```
/reload
```

Дальше десять партий по 16 зданий. Для каждой — две команды подряд:

```
/function lmpc_struct:go_1
/function lmpc_struct:place_1
```

Между ними подожди секунды три, пока прогрузятся чанки.

Потом `go_2` / `place_2`, потом `go_3` / `place_3` — и так до десяти.

`go` телепортирует к месту партии, `place` ставит там 16 зданий.

## Шаг 4. Выйти из мира

Выйти в главное меню. **Обязательно.** Пока мир открыт, ничего не
записано на диск и скрипт ничего не найдёт.

## Шаг 5. Достать здания

Снова двойной клик по **`RUN.bat`**, тот же мир, пункт:

```
2) Достать здания из мира
```

Пара минут — и он напечатает список зданий с размерами. Файлы сам
положит куда надо:

```
<папка игры>\config\worldedit\schematics\buildings
```

## Шаг 6. Пользоваться

В игре Axiom: `File → Import Schematic` → выбрать здание →
`Create Blueprint`.

Дальше блюпринт ставится кистью, с предпросмотром.

---

## Если что-то пошло не так

**«Python не найден»**
Не поставлена галочка «Add Python to PATH». Переустанови Python
и поставь её.

**У части зданий написано «пусто (не сгенерилось)»**
Нормально. Не все структуры умеют появляться в плоском мире.

**Здания вышли огромными кубами 256×200×256**
Скрипт запустили не на том мире — на обычном, а не на плоском
пустом. Он выгреб кусок ландшафта. Удали папку `buildings`
и сделай отдельный суперплоский мир по шагу 1.

**Здание обрезано по краю**
Оно шире 256 блоков. Такое придётся забрать вручную выделением
в Axiom.

**Проверить, что скрипты вообще живы**
В терминале, из папки архива:

```
python tools\world2schem.py --selftest
python tools\nbt2schem.py --selftest
```

Обе должны написать «самопроверка прошла».

---

## Что ещё лежит в архиве

- `tools\run.py` — то, что запускает `RUN.bat`
- `tools\world2schem.py` — сама выемка зданий из мира
- `tools\nbt2schem.py` — конвертер отдельных `.nbt` из джарника мода.
  Это **куски** домов, а не целые дома; нужен редко
- `tools\make_catalog.py` — пересобирает датапак, если набор модов
  поменялся:
  `python tools\make_catalog.py <папка с модами> -o tools\structure_catalog`
