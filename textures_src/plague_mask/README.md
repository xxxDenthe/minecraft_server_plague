# Plague Mask — тряпичная повязка на лицо

Сложенная полоса грязного льна: серо-бежевая, в пятнах, края обтрёпаны,
крестьянская работа. Две завязки идут вокруг головы. Это **не клюв чумного
доктора** — на макушке ничего нет, вперёд ничего не торчит.

Рисуется слоем `PlagueMaskLayer` поверх модели игрока.

---

## 1. Что где лежит

```
textures_src/plague_mask/
├── assets/textures/
│   ├── entity/plague_mask.png       ← слой на лицо, 64x64
│   └── item/plague_mask_item.png    ← иконка в инвентаре, 16x16
├── source/
│   ├── plague_mask.py               ← рисует обе картинки
│   └── pngio.py                     ← запись PNG (общий, из plague_bloom)
└── README.md
```

Скрипт сам кладёт копию слоя прямо в мод:

```
plaguecore/src/main/resources/assets/plaguecore/textures/entity/plague_mask.png
```

## 2. Как перерисовать

```
cd textures_src/plague_mask/source
python plague_mask.py
```

Сначала прогоняются проверки, потом пишутся файлы. Если картинка уехала —
скрипт падает с ошибкой, а не молча портит текстуру.

Что проверяется:

- слой ровно 64×64;
- ни одного пикселя вне головы (блок 32×16 в левом верхнем углу);
- на макушке и снизу головы пусто — это повязка, а не капюшон;
- строка глаз `y=12` пустая целиком — игрок видит;
- верхняя завязка `y=11` идёт без разрывов над ушами и по затылку,
  и **не** пересекает лицо;
- нижняя завязка `y=14` идёт кольцом вокруг всей головы — иначе со спины
  повязка пропадёт.

## 3. Раскладка

Обычный шаблон скина. Голова — левый верхний угол, 32×16:

```
        x:  0───7   8──15   16─23   24─31
  y: 0─7    пусто   верх    низ     пусто
  y: 8─15   правый  ЛИЦО    левый   затылок
```

Строки x0..31 идут подряд, поэтому горизонтальная полоса обходит всю голову.

| строка | что нарисовано |
|--------|----------------|
| `y=11` | верхняя завязка: над ушами и по затылку, лицо не трогает |
| `y=12` | **пусто** — тут глаза |
| `y=13` | верхний сгиб ткани + узел сзади |
| `y=14` | основное полотно + нижняя завязка кольцом |
| `y=15` | обтрёпанный низ |

Картинка задана таблицей `HEAD_ROWS` в `plague_mask.py`: один символ = один
пиксель. Цвета символов — в `PAL`.

| символ | что это |
|--------|---------|
| `.` | прозрачно |
| `b` `o` | лён: основа / светлый край |
| `d` | сгиб, тень |
| `n` | пятно грязи |
| `f` | обтрёпанный, протёртый край |
| `c` `C` | завязка / узел |

## 4. Расхождение со спекой

Мне сказали «ткань `y = 12 … 15`». Так было в заглушке — и она закрывала
глаза: у ванильного скина глаза стоят ровно на `y=12`, рот на `y=13`.

Я опустил ткань на строку: `y = 13 … 15`. Глаза открыты, рот и подбородок
закрыты. Если нужно строго по спеке — в `plague_mask.py` перенести ключ `13`
на `12` и убрать проверку `EYE_ROW not in HEAD_ROWS`.
