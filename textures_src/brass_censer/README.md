# Brass Censer — кадило

Иконка предмета `lmpc_classes:brass_censer`. Кадило на короткой цепи:
продырявленный купол, потемневшая латунь и тёмное железо, копоть на дне и
вокруг дырок, тонкая струйка бледного дыма уходит вверх и вбок.
Ничего не светится.

Это **предмет, а не блок**. Поставить нельзя, только носить и держать в руке.

---

## 1. Что где лежит

```
textures_src/brass_censer/
├── assets/
│   ├── models/item/brass_censer.json   ← модель предмета (item/generated)
│   └── textures/item/brass_censer.png  ← иконка 16x16
├── source/
│   ├── brass_censer.py                 ← рисует иконку
│   └── pngio.py                        ← запись PNG (общий, из plague_bloom)
└── README.md
```

## 2. Как перерисовать

```
cd textures_src/brass_censer/source
python brass_censer.py
```

Сначала проверки, потом запись. Если картинка уехала — скрипт падает с
ошибкой, а не портит текстуру молча.

Что проверяется:

- ровно 16×16, все символы известны;
- цепь не рвётся от кольца сверху до крышки — иначе кадило висит в воздухе;
- каждая дырка в куполе окружена латунью со всех четырёх сторон — дырка на
  краю читается как откушенный кусок, а не как отверстие;
- дым не касается металла — прилипший дым читается как белёсое пятно на
  крышке, а не как струйка.

## 3. Как устроена картинка

Таблица `ROWS` в `brass_censer.py`: 16 строк по 16 символов, один символ =
один пиксель. Цвета — в `PAL`.

| символ | что это |
|--------|---------|
| `.` | прозрачно |
| `B` `b` `r` | латунь: светлая / средняя / тень |
| `i` `I` | железо: цепь и обод |
| `o` | дырка в куполе |
| `s` | копоть |
| `S` `w` | дым: ближе / тает |

Сверху вниз: кольцо и цепь (строки 0–3), купол с дырками (4–7), железный
обод (8), чаша (9–11), закопчённое дно (12), ножка (13). Дым — справа,
строки 0–3.

## 4. Куда ставить в сборке

| файл | путь в ресурспаке |
|------|-------------------|
| `assets/textures/item/brass_censer.png` | `assets/lmpc_classes/textures/item/brass_censer.png` |
| `assets/models/item/brass_censer.json` | `assets/lmpc_classes/models/item/brass_censer.json` |

Неймспейс взят `lmpc_classes` — как у `clerics_pendant` и `plague_bloom`.
Если предмет живёт в `plaguecore`, поменять его в двух местах: в `.json`
и в путях выше.

## 5. Что осталось не сделано

- Нет предмета в коде — только иконка и модель.
- Дым не анимирован. Если нужен живой дымок — это уже частицы в коде,
  а не текстура.
