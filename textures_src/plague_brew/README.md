# Plague Brew — отвар чумы

Иконка предмета `plaguecore:plague_brew`. Питьевая склянка, держится в руке,
пьётся как обычная бутылка с водой. Это **не блок** и не размещаемый предмет.

Ретекстур ванильной `minecraft:item/glass_bottle`. Силуэт взят из неё
пиксель-в-пиксель: ни один контурный пиксель не выкинут, за границы контура
ничего не вылезает. Отличие одно — ванильная бутылка пустая (внутри дырка),
а эта полная, поэтому внутренность залита жижей.

Грубое тёмное стекло, внутри бледная мутная жижа с комками и осадком.
На горлышке тряпка, перевязана бечёвкой. Свечения нет, магии нет — это
аптекарское снадобье, а не зелье.

---

## 1. Что где лежит

```
textures_src/plague_brew/
├── assets/
│   ├── models/item/plague_brew.json      ← модель предмета (item/generated)
│   └── textures/item/plague_brew.png     ← иконка 16x16
├── source/
│   ├── plague_brew.py                    ← рисует иконку
│   ├── glass_bottle_vanilla.png          ← ванильный референс (1.21.11)
│   └── pngio.py                          ← чтение/запись PNG (общий, из plague_bloom)
└── README.md
```

## 2. Как перерисовать

```
cd textures_src/plague_brew/source
python plague_brew.py
```

Скрипт сначала проверяет силуэт по `glass_bottle_vanilla.png` и падает с
ошибкой, если картинка уехала от ванильной формы. Потом пишет PNG.

Сама картинка — таблица `ROWS` в `plague_brew.py`: 16 строк по 16 символов,
один символ = один пиксель. Цвета символов в `PAL`.

| символ | что это |
|--------|---------|
| `.` | прозрачно |
| `D` `g` `h` | тёмное стекло: контур / стенка / тусклый блик |
| `S` | пустое горлышко, видно сквозь стекло |
| `L` `l` `m` `n` | жижа: поверхность / основа / комки / осадок |
| `c` `C` `s` | тряпка: основа / светлое / тень |
| `t` `T` | бечёвка |

## 4. Что осталось не сделано

- Предмет в коде есть давно: `PlagueBlocks.PLAGUE_BREW` в `plaguecore`,
  с лечением и звуком. Здесь была только иконка, теперь она заведена
  в мод и модель на неё переключена.
- Нет варианта «выпитая склянка». Если понадобится — тот же силуэт,
  только жижу заменить на `S`, и тряпку снять.
