# Class Codex — Гримуар призвания

Иконка предмета `lmpc_classes:class_codex` (`ClassItems.java:32`). Тёмный
зеленовато-бирюзовый том, лежащий обложкой вверх: светлый блик по верхней
крышке, торец страниц справа, из книги свисает коричневая закладка.

## 1. Текстуру нарисовал владелец, скрипта тут нет

Иконку 2026-09-07 нарисовал владелец и положил файлом
`E:\BLOCKBENCHCLAUDE\textures_src\grimuar.png`. Оригинал лежит рядом
как `source/grimuar.png` — **править надо его**, а не копию в
`assets/`, и после правки перекладывать по таблице из раздела 3.

Генератор на питоне (`class_codex.py`), рисовавший коричневый том
с ремнём, удалён: он был заглушкой на время, пока своей картинки не
было, и держать мёртвый код рядом с живой текстурой незачем. Если
когда-нибудь понадобится вернуться к рисованию скриптом, образец
приёма — соседний `textures_src/brass_censer/source/brass_censer.py`.

## 2. Что где лежит

```
textures_src/class_codex/
├── assets/
│   ├── models/item/class_codex.json   ← модель предмета (item/generated)
│   └── textures/item/class_codex.png  ← иконка 16x16, RGBA
├── source/
│   └── grimuar.png                    ← оригинал владельца, как отдан
└── README.md
```

Копия в `assets/` отличается от оригинала одним: оригинал сохранён
с палитрой (режим `P`), в мод кладётся `RGBA`. Майнкрафт понимает оба,
но с палитрой сложнее работать любому инструменту, который её потом
откроет, поэтому перевод делается один раз здесь:

```
python -c "from PIL import Image; Image.open('source/grimuar.png').convert('RGBA').save('assets/textures/item/class_codex.png')"
```
