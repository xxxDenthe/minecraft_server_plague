# Class Codex — Гримуар призвания

Иконка предмета `lmpc_classes:class_codex` (`ClassItems.java:32`). Закрытый
том, стоящий корешком влево: кожаная обложка, справа торец страниц, поперёк
всего — ремень с латунной пряжкой. Это единственный предмет мода, который
до 2026-09-07 оставался на ванильной текстуре `minecraft:item/writable_book`.

## 1. Почему такие цвета

Не выдуманы. Взяты пипеткой из его же экрана —
`assets/lmpc_classes/textures/gui/codex_background.png`: пергамент
`#FDF9ED`, коричневая кожа `#70462D`, тёплый загар и тёмная обводка
оттуда же. Смысл в том, что предмет в руке и раскрытый экран должны
читаться как одна вещь, а не как две разных книги.

Фиолетового в иконке нет намеренно. По палитре чумы
(`docs/superpowers/notes/2026-09-03-palitra-chumy.md`) фиолетовый —
скупой акцент **на самой заразе**; гримуар к заразе отношения не имеет,
это вещь класса.

## 3. Как перерисовать

```
cd textures_src/class_codex/source
python class_codex.py
```

Сначала проверки, потом запись: если картинка уехала, скрипт падает
с ошибкой, а не портит текстуру молча. Что проверяется:

- ровно 16×16, все символы известны;
- **контур замкнут** — любой пиксель на границе с пустотой обязан быть
  обводкой, иначе на тёмном фоне инвентаря том теряет силуэт;
- **ремень пересекает обложку целиком** и его пряжка ложится на торец
  страниц — ремень с дыркой посередине читается как царапина на коже,
  а не как то, чем том стянут;
- **страницы не заезжают на корешок** — светлый пиксель слева мгновенно
  превращает закрытый том в раскрытую книгу;
- **корешок сплошной** по всей высоте тела: на нём держится «закрытость».

## 4. Как устроена картинка

Таблица `ROWS`: 16 строк по 16 символов, один символ — один пиксель,
цвета в `PAL`.

| символ | что это |
|--------|---------|
| `.` | прозрачно |
| `o` | обводка, тёплая почти-чернота |
| `d` | кожа, самая тёмная: корешок и нижняя тень |
| `l` `L` | кожа: средняя / освещённая |
| `s` | ремень |
| `q` `p` `P` | торец страниц: тень / середина / свет |
| `b` `B` | латунная пряжка: тень / свет |

Столбцы: `1` обводка, `2` корешок, `3–10` обложка, `11–12` торец страниц,
`13` обводка. Строки `2` и `13` — верх и низ, углы срезаны, чтобы том
не читался кирпичом. Ремень — строки `7–8`.
