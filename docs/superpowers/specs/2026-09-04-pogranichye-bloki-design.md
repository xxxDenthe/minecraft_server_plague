# Блоки для Пограничья — задание художнику

**Дата:** 2026-09-04
**Статус:** к реализации
**Подсистема:** 4 «Мир», зона Пограничье
**Кто делает:** владелец (текстуры + регистрация блоков в `plaguecore`)
**Основа:** `docs/superpowers/notes/2026-09-04-mir-tri-zony-reshenie.md`
(Пограничье курируется вручную, WorldEdit, поверх структур из модов —
в первую очередь Dungeons and Taverns)

---

## 1. Зачем вообще новые блоки

Плёнка `plague_growth` растёт на любой грани любого блока, а
`blight_vine` свисает с чего угодно — обвесить ими структуру из чужого
мода можно уже сегодня, без единой новой текстуры. Поэтому список ниже
короткий: новое рисуем только там, где готового решения нет.

Плотность декора привязана к тем же процентам, что уже в спеке ядра
(раздел 5 `plague-core-design.md`): у края города — редкие трещины
и паутина (уровень 1, ~10%), в середине Пограничья — заколоченные окна,
лоза погуще (уровень 2, ~35%), у фронта Гнили — стены затянуты плёнкой
почти целиком, фиолетовые мешки у оснований (уровень 3+, ~70%+).

## 2. Уже есть — просто применить руками при курации

Ничего рисовать не надо, это готовые блоки мода:

| Блок | Где ставить |
|---|---|
| `plague_growth` | плёнка на стенах и крышах, основной инструмент decay |
| `blight_vine` | свисает с балок, оконных проёмов, обломанных карнизов |
| `spore_sac` | только у оснований построек, только уровень 3+ |

## 3. Взять из ванили/модов — тоже без новых текстур

Уже серые/тёмные, в палитру ложатся как есть:

| Блок | Зачем |
|---|---|
| Cobweb | маркер заброшенности |
| Cracked stone bricks / cracked deepslate bricks | трещины в кладке, без зелени |
| Polished blackstone / deepslate tile | тёмные акценты на крышах |
| Iron bars, chain | забитые окна, решётки |
| `rotted_log` (уже наш) | несущие балки, которые уже подгнили |
| Баннер с рваным паттерном (loom, любой цвет из палитры) | флаги — не блок, крафтится, кода не требует |

## 4. Новое — то, что нужно нарисовать и завести как блок

Список короткий специально — доски уже частично решены (постройки
игроков плесневеют через оверлей на `PLANKS`), это не дублируем.

| Блок | Зачем | Вид |
|---|---|---|
| `rotted_planks` | ванильные доски тёплые и не подходят под палитру; нужен холодный серый вариант для стен/пола структур Пограничья | обычная доска, 1 текстура |
| `boarded_window` | заколоченное окно вместо стекла — главный маркер «эвакуированного» здания | планка поверх стекла или глухая панель, 1 текстура |
| `rotted_thatch` | если у структур из Dungeons and Taverns соломенные крыши — нужен обесцвеченный вариант вместо жёлтой соломы | curved-плита, 1 текстура |

Три текстуры, не больше. Если `rotted_thatch` не понадобится (крыши
окажутся не соломенными) — можно выкинуть, вычеркнуть отсюда, не ждать
согласования.

## 5. Палитра

**Важно:** актуальное направление — из обновления 2026-09-04
в `2026-09-03-palitra-chumy.md`, оно отменяет более раннее правило
«серые уходят в лиловое». Если увидишь старый пример с лиловым
подтоном — не ориентируйся на него.

```
Тон:        бледный, выцветший, нейтральный или чуть тёплый
            (зола, кость, бетон) — НЕ холодный, НЕ лиловый
Референс:   lmpc_shade 0.4.0 — база #2C2B28, туман/небо #4A4842
Фиолетовый: только на самой заразе (plague_growth, spore_sac),
            для трёх блоков этого списка — не использовать вообще,
            они про постройку человека, а не про саму чуму
```

Правила для генератора картинок (без изменений от прошлого спека):

```
desaturated, pale, flat colors, no gradients, hard pixel edges
16x16 pixel art
```

Отдавать в 1024, сжимает `tools/TextureBaker.java` сам.

## 6. Чего этот документ не решает

Не выбирает конкретные структуры Dungeons and Taverns для Пограничья —
это ручная курация WorldEdit'ом, отдельная задача, не про блоки. Не
трогает ядро и заражение игрока — это чужая территория в параллельной
сессии.
