# Токсичный туман из заражённой земли — дизайн

Статус: не реализовано. Кому браться: владельцу `plaguecore`, когда
подсистема «Мир» дойдёт до готовых, стабильных ID блоков заражения.
Пока рано — блоки могут ещё поменяться, а этот спек завязан на их
конкретные ID.

## Идея

У мода SubtleEffects (уже стоит в паке) есть «дымовые гейзеры» —
частицы серого дыма, которые сами поднимаются из заданных блоков.
Если добавить в список этих блоков наши блоки заражения, дым начнёт
идти прямо из гнилой земли и наростов — атмосферный «токсичный туман»
без единой строчки Java-кода, потому что весь спавн частиц уже
реализован в чужом моде.

Это продолжение того же приёма, которым 2026-09-04 занижена плотность
светлячков и выключен их дубль у мода Particular — конфиги сторонних
модов правятся текстовыми файлами в `launcher/pack-config/`, а не
кодом в `lmpc_shade`. См. `launcher/pack-config/README.md`.

## Где крутить

Файл: `launcher/pack-config/config/subtle_effects/environment.toml`
(уже существует — сейчас в нём только раздел `[fireflies]`). Добавить
рядом раздел `[geysers]`, поле `smokeGeyserSpawnableBlocks` — список
ID блоков, из которых имеет право пойти дым.

Формат конфига — TOML мода SubtleEffects (библиотека fzzy_config).
Файл частичный: любые разделы и поля, которых в нём нет, мод
дозаполнит собственными дефолтами сам — трогать нужно только то, что
меняем.

Смежные поля того же раздела `[geysers]`, если понадобится:

- `smokeGeyserSpawnChance` (число 0–50, по умолчанию 5) — как часто
  гейзер вообще появляется, где может.
- `smokeGeyserActiveTime` / `smokeGeyserInactiveTime` (тики, по
  умолчанию активен ~300, пауза ~500) — сколько дымит и сколько молчит.

Крутить эти три вживую на запущенном клиенте, как принято в проекте —
конкретные цифры не сохранять на глаз, добиться по ощущениям.

## Важно: список блоков — не добавить, а переписать целиком

`smokeGeyserSpawnableBlocks` — обычный TOML-массив. Мод его не
дополняет, а берёт как есть: что записано в файле, то и становится
списком целиком. По умолчанию там блоки лавы/незера (дым уже идёт
у лавы без наших правок).

Порядок действий:

1. Один раз запустить полный клиентский пак (не `./gradlew runClient`
   в `plaguecore` — там нет SubtleEffects, это чистое dev-окружение
   без модпака). Мод сам создаст `config/subtle_effects/environment.toml`
   с текущими дефолтами, включая полный список `smokeGeyserSpawnableBlocks`.
2. Скопировать этот список к себе в `launcher/pack-config/config/subtle_effects/environment.toml`,
   в раздел `[geysers]`.
3. Дописать в конец списка ID наших блоков заражения (ниже).
4. Проверить на живом клиенте, что дым по-прежнему идёт и у лавы,
   и у заражённой земли.

## Какие блоки заражения годятся

Из `plaguecore/src/main/java/dev/denthe/plaguecore/mc/PlagueBlocks.java`
(десять блоков материализации, дизайн ядра, раздел 7):

```
plaguecore:rotted_dirt
plaguecore:rotted_grass
plaguecore:rotted_stone
plaguecore:rotted_log
plaguecore:blighted_leaves
plaguecore:blighted_grass
plaguecore:blighted_tall_grass
plaguecore:plague_growth
plaguecore:blight_vine
plaguecore:spore_sac
```

Не обязательно тащить все десять. Логичнее всего дым смотрится у
блоков, которые и есть сама зараза, а не просто заражённая порода:

- `plague_growth`, `spore_sac` — наросты и мешки, дым из них читается
  как что-то живое и опасное
- `rotted_dirt`, `rotted_stone` — сама заражённая земля, дым как
  испарения из почвы

`rotted_log`, `blighted_leaves`, `blighted_grass`, `blighted_tall_grass`,
`blight_vine` — декоративная растительность Гнили, дым из них будет
на каждом кусте травы и может оказаться слишком часто. Начать без них,
добавить потом, если мало.

## Не забыть перепроверить на дубль

Прежде чем что-то добавлять, стоит заново заглянуть в конфиг мода
Particular (`config/particular-common.toml`) — у него, как и со
светлячками, может найтись своя система тумана/дыма/пыли с похожим
названием (`caveDust`, генерик-категории частиц). Если найдётся
дубль — решить так же, как со светлячками: оставить включённым только
один источник.

## Как раздать игрокам

Файл лежит в managed-директории `config` (раздаётся по умолчанию,
отдельный флаг `--managed` не нужен). После правки:

```
cp -r launcher/pack-config/* launcher/pack-build/
node launcher/tools/publish-pack.js --repo xxxDenthe/minecraft_server_plague \
     --tag pack --token <ghp_...>
```

Токен для `publish-pack.js` — у владельца лаунчера; сессии Claude без
него могут только подготовить файлы и закоммитить исходники.
