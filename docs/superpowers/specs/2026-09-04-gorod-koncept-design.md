## 1. Форма и планировка

Форма — подкова или кольцо, интуитивно на глаз, не строгая сетка.

Улицы прокладываются **заранее и целиком**, с уже нарезанными зонами
под жилые кварталы — размеченные, огороженные участки, а не голое поле.
Так город выглядит обжитым с первого дня сессии, даже пока не все дома
построены игроками.

**Диаметр — черновой ориентир 300–400 блоков** (первая прикидка 180–220
была признана маленькой). Число не догма, поправляется на месте — но
даёт запас, чтобы не тесниться на ключевых зданиях и участках.

Участки под жильё — **12×12**, подтверждено.

### Как строить кольцо/подкову без порчи геометрии

Minecraft-сетка не поворачивается на произвольный угол без потерь —
это ограничение движка, а не мода: `WorldEdit //rotate` (уже
установлен) даёт **честный поворот только на 90°/180°/270°**,
произвольный угол требует ре-семплинга вокселей и портит прямые стены,
окна, двери. У любого другого инструмента (в т.ч. Axiom) та же
физика, ставить его под это не нужно.

**Решение — собирать кольцо из прямых сегментов улицы.** Каждое
здание стоит в своём сегменте строго по осям (0/90/180/270°), кривизна
всей улицы получается из того, что сегменты слегка довёрнуты друг
к другу на стыках, а не из гнутой геометрии одного здания. Стыки
прикрывает то, что и так не требует точности — забор, сад, поленница,
неровная брусчатка. Это стандартный приём для круглых/подковообразных
городов в Minecraft.

Ширина Пограничья вокруг города — не решена, это следующий шаг
(раздел 5).

## 2. Строения

| Строение | Кто строит | Зачем |
|---|---|---|
| Стены + главные ворота | мы | единственный проход внутрь, оборона |
| Ратуша | мы | комната выбора класса (доска призвания), библиотека с лором, зал совета, архив снимков Летописца |
| Таверна | мы | общее место игроков, погреб под блюда FarmersDelight |
| Мастерская Кузнеца | мы | сборка деталей Очистителя — второй шаг цепочки реагента |
| Дом Клирика | мы | алхимический стол + варочная стойка — первый шаг цепочки реагента |
| Огороженная ферма | мы | безопасная грядка `plague_bloom` для Фермера, должна быть внутри стен с первого дня |
| Кладбище / мемориал | мы | доска памяти погибших от чумы — даёт вес механике «−0.5 сердца навсегда» |
| Городская площадь с колоколом | мы | точка сбора, тревога при набеге |
| Жилые кварталы | игроки | размеченные участки, застройка свободная |
| Рынок/склад | игроки, по желанию | общий сундук-хаб, не критично |

Смотровая башня из списка снята: владелец решил оставить обзорные
точки на усмотрение игроков, а не предпостраивать.

## 3. Привязка строений к классам

| Класс | Строение | Механика |
|---|---|---|
| Клирик | Дом Клирика | алхимический стол (обработка `plague_bloom`), варочная стойка (`clerics_brew`) |
| Кузнец | Мастерская Кузнеца | Create-машины, сборка деталей Очистителя |
| Фермер | Огороженная ферма | грядка `plague_bloom`, культура вместо похода в Гниль |
| Летописец | Ратуша (архив снимков) | `exposure`-снимки в item frame — лор растёт сам за сессию, без кода |

Цепочка реагента (`plague-core-design.md`, раздел 10.4 и
`klassy-design.md`, раздел 8) физически идёт по городу: ферма/Гниль →
дом Клирика → мастерская Кузнеца → `cleansing_agent`.

## 4. Визуальный стиль

**Главная идея:** палитра чумы — намеренно холодная и блёклая
(`docs/superpowers/notes/2026-09-03-palitra-chumy.md`), чтобы читаться
как болезнь. Город внутри стен должен быть её зеркальной
противоположностью — тёплым, живым, обжитым. Контраст на границе со
стеной должен быть заметен без единого слова текста.

**Материалы:** тёплое дерево, тёплый камень. Холодные серые ванильные
блоки зарезервированы за гнилью и Пограничьем — в городе их избегаем.

**Уже установленные моды, дающие декор без рисования нового:**

| Мод | Что даёт |
|---|---|
| `handcrafted` | мебель для интерьеров — стулья, столы, шкафы, полки. Жилые дома, Ратуша, Таверна |
| `supplementaries` | свечи, настенные бра, таблички, мелкий декор |
| `copycats` | маскировка блоков под другие текстуры — гибкость фасадов без новых моделей |
| `sit` | сидения на лестницах и плитах — мелкая живая деталь для Таверны |
| `dungeons-and-taverns` | референсы/куски декора можно подсматривать даже у структур, которые физически уходят в Пограничье |
