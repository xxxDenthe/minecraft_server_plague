# Сердце чумы — дизайн

**Дата:** 2026-09-05
**Подсистема:** 6 «Финал», первый кусок — сама сущность Сердца
**Статус:** утверждено владельцем

## Что делаем и чего не делаем

Делаем **только объект**: Сердце чумы можно поставить в мир и разбить
по кускам. Модель, анимация, разрушение, звук, частицы.

Не делаем: логово, волны мобов, лор-цепочку к нему, очистку мира при
смерти Сердца, конец сессии. Это остаток подсистемы 6, у него будет
свой дизайн. Здесь оставлен один пустой крючок, куда та подсистема
впишется одной строкой.

## Исходник

Модель лежит в `rotten_heart/` — сделана в Blockbench, формат Bedrock
Entity, рендерится через GeckoLib. Разбор устройства — `rotten_heart/README.md`.

```
геометрия     geometry.rotten_heart, 297 кубов, 23 кости
анимация      heartbeat, 1.2 с, зациклена
текстура      атлас 128×64, семь плиток плоти и корней
габариты      ~2.6 × 2.9 × 2.3 блока
```

Три родительские кости (`heart_body`, `arteries`, `roots`) держат
анимацию — их не трогаем. Двадцать дочерних (`body_p1..p8`,
`arteries_p1..p4`, `roots_p1..p8`) — это и есть куски.

## GeckoLib

`geckolib-neoforge-1.21.1-4.9.2.jar` уже лежит в паке (`mods/MODLIST.md`,
строка 53). В сборку мода подключается из Cloudsmith:

```
maven { url = 'https://dl.cloudsmith.io/public/geckolib3/geckolib/maven/' }
implementation "software.bernie.geckolib:geckolib-neoforge-1.21.1:4.9.2"
```

`implementation`, а не `compileOnly` как у voicechat: GeckoLib нужен
и в дев-запуске, иначе рисовать сердце нечем. В `neoforge.mods.toml`
пишется обязательная зависимость `geckolib` с диапазоном `[4.9,5.0)` —
версия у мода чистая, `4.9.2`, ловушки voicechat здесь нет.

## Сущность

`mc/RottenHeart.java`, наследник `Mob`. Не `PathfinderMob`: Сердце
стоит на месте, навигация ему не нужна и стоит тиков.

Что отключено и почему:

| Что | Почему |
|---|---|
| ИИ и цели | Сердце не двигается вовсе |
| гравитация | ставится вручную, в том числе в воздухе логова |
| толкание сущностями | иначе моб-волна растолкает Сердце по залу |
| урон от огня, лавы, утопления | ломать его должны игроки, а не декорации |
| сдувание взрывом | оно должно стоять там, где поставили |
| естественный спавн | появляется только рукой GM |

Здоровье по умолчанию **200 HP**, число уходит в конфиг. Хитбокс
2.6 × 2.9 — под модель, чтобы по нему попадали.

## Разрушение

Двадцать кусков. Общее здоровье; порядок отваливания фиксированный
и от игрока не зависит:

```
сначала  roots_p1..p8       корни, 8 кусков
потом    arteries_p1..p4    ветки, 4 куска
в конце  body_p1..p8        тело, 8 кусков
```

Сколько кусков отвалилось, считаем **из здоровья**, а не из числа
ударов. Так значение переживает загрузку мира, лечение и `/data`:

```
отвалилось = round((1 − здоровье / максимум) × 20)
```

Хранение — один `int`, битовая маска: бит `i` поднят, значит кусок
номер `i` отвалился. Синхронизируется на клиент через `SynchedEntityData`,
пишется в NBT ключом `BrokenMask`.

Расчёт маски по здоровью — чистая функция, без Minecraft:
`core/HeartDecay.java`, покрыта JUnit. Пакет `core` остаётся чистым,
`CorePurityTest` не ослабляется.

### Что видит и слышит игрок

- Кусок отвалился → облако пепла у места слома, звук ломающегося
  корня с низким тоном.
- Биение замедляется по мере урона: скорость анимации
  `0.35 + 0.65 × доля здоровья`. Умирающее сердце бьётся медленно.
- Последний кусок → вспышка, глухой удар, сущность исчезает.

Прицельных хитбоксов на куски нет намеренно. Владелец выбрал простой
вариант: игроку всё равно не видно, какой кусок он «выбрал», а двадцать
отдельных сущностей-мишеней ломались бы при телепорте и лагах.

## Рендер

`client/RottenHeartModel.java` — три пути к ресурсам, больше ничего.

`client/RottenHeartRenderer.java` — в `preRender` каждый кадр проходит
по двадцати костям и выставляет `setHidden` **и скрытым, и видимым**.
Это не перестраховка: `BakedGeoModel` общий на все сущности типа,
выставить флаг один раз — значит продырявить соседнее Сердце.

## Установка в мир

- `/summon plaguecore:rotten_heart` — работает от регистрации.
- Яйцо призыва `rotten_heart_spawn_egg` в творческой вкладке «Чума».
  Цвета держат палитру: тёмно-серая основа `0x2E2A28`, фиолетовая
  крапина `0x5C3A5C` — по заметке `2026-09-03-palitra-chumy.md`,
  где Сердцу отведён самый заметный акцент.

## Конфиг

Новая секция `[heart]` в `config/plaguecore-common.toml`:

```
health = 200.0    здоровье Сердца; двадцать кусков делят его поровну
```

Число кусков в конфиг не выносится — оно задано моделью.

## Крючок для подсистемы 6

В `RottenHeart` метод `сердцеУничтожено()` вызывается один раз при
смерти и сейчас пуст, кроме частиц и звука. Очистка мира, конец сессии
и всё прочее впишутся туда, когда подсистему 6 спроектируют.

## Проверка

Автоматически: `core/HeartDecay` под JUnit — 0 урона даёт 0 кусков,
полный урон даёт 20, середина даёт 10, порядок битов правильный,
значение не выходит за границы.

Руками в дев-клиенте:
1. `/summon plaguecore:rotten_heart ~ ~ ~5` — сердце стоит и бьётся.
2. Бить мечом — куски отваливаются снизу вверх, летит пепел.
3. Выйти и зайти в мир на середине — дырки на месте.
4. Добить — вспышка, исчезло.
