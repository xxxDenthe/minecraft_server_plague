# Город: генератор схемы вместо ручной расстановки

**Дата:** 2026-09-05
**Статус:** решение владельца, черновая болванка города готова
**Опирается на:** `specs/2026-09-04-gorod-koncept-design.md`,
`notes/2026-09-03-palitra-chumy.md`

---

## Решение

Черновик города собирает скрипт-генератор, а не расстановка блоков в живой
игре. Причина — цена: гонять блоки через MCP поблочно стоит порядка
500k–2M токенов на город 150×150, скрипт — 10–30k, потому что токены
уходят на код, а не на блоки. Доводка (мебель `handcrafted`,
`supplementaries`, фасады `copycats`) остаётся ручной, в Axiom.

## Где лежит

```
tools/citygen/city_gen.py    генератор -> plague_city.schem (Sponge, 1.21.1)
tools/citygen/preview.py     вид сверху -> preview.png, проверка без игры
tools/citygen/validate_blocks.py  сверка блоков с ассетами игры
tools/citygen/plague_city.schem
```

`validate_blocks.py` гонять перед каждой отдачей схемы. Первый блин не
загрузился в Axiom из-за одного несуществующего блока
(`polished_granite_wall`, у полированного гранита нет варианта «стенка» —
только `granite_wall`). Парсер бракует всю схему целиком и координату
не показывает, поэтому имена и свойства сверяются с
`assets/minecraft/blockstates/*.json` из клиентского джарника NeoForge,
а не с памятью.

Зависимости: `pip install mcschematic pillow`.

## Что генерируется

Восьмиугольник 150×150×23, земля 3 слоя (низ схемы на 4 блока ниже травы).

- Площадь с колодцем и колоколом под навесом
- Ратуша (2 этажа, библиотека, постамент под доску призвания, зал совета)
- Таверна (кухня, стойка, погреб под лестницей), Мастерская Кузнеца
  (наковальня, горн с трубой), Дом Клирика (варочные стойки, садик)
- Огороженная ферма 25×19 с каналами, кладбище с мемориалом
- 17 участков 12×12 — огорожены, размечены, пустые: застройка за игроками
- 11 готовых домов внутреннего пояса, чтобы город читался обжитым
- Кольцевая улица, три спицы, стена высотой 7 с 9 башнями и воротами на юге

Только ванильные блоки: схема грузится даже без модпака. Палитра тёплая
(грязевой кирпич, гранит, ель/дуб, красный кирпич) — контраст с холодной
серой чумой за стеной.

## Отклонения от ТЗ

- **Размер 150 вместо 300–400 из ТЗ** — так заказал владелец. При 150 стена
  проходит на радиусе 69, участков помещается 17, диагональные сегменты
  пояса участков впритык. Под 300–400 в скрипте меняются только константы
  радиусов вверху файла.
- **Грядка `plague_bloom`** на ферме заменена пшеницей: блок из
  `plaguecore`, в ванильную схему не кладём. Ставится руками после вставки.
- **Спицы всего три** (восток, запад, юг): север закрывает Ратуша, стоящая
  во главе парадного подхода от площади.
