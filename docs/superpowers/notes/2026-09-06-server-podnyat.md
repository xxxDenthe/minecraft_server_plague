## Решения, которые пришлось принять

**`online-mode=false`.** Не выбор, а следствие: лаунчер входит
в offline-режиме и считает UUID как `UUID.nameUUIDFromBytes
("OfflinePlayer:<ник>")` (`launcher/src/main/offline.js`, спек 11).
При `online-mode=true` сервер считал бы UUID иначе, и игрок при каждом
входе получал бы нового персонажа.

**Из этого следует одно обязательное действие перед тем, как открывать
порт наружу: включить белый список.** При `online-mode=false` любой,
кто знает адрес, заходит под любым ником — включая ник оператора.
Пока `white-list=false`, потому что ников восьмерых у меня нет. Порядок:
`whitelist add <ник>` на каждого, затем `whitelist on`, затем
`enforce-whitelist=true` в `server.properties`.

**19 модов не поехали на сервер.** Клиентские: `sodium` и его спутники,
`entity_model_features`, `entity_texture_features`, `lambdynamiclights`,
`particlerain`, `ok_zoomer`, `Controlling`, `ImmersiveUI`, `InvMove`
(+`Compats`), `MouseTweaks`, `better-advanced-tooltips`,
`clickthrough-plus`, `punchy`, `sounds`, `extrasounds`, `atmospherics`,
`CustomSkinLoader`. Ни один из них не регистрирует блоков и предметов,
поэтому расхождения регистров с клиентом нет — у игрока просто есть
лишние картинки и звуки, которых серверу знать не нужно.

Отбирал не по `mods.toml`: поле `side` там встречается **и внутри
`[[dependencies.*]]`**, и наивный поиск первого `side = "CLIENT"`
даёт ложные срабатывания (например, на `sophisticatedcore`, который
серверу нужен). Итог — по факту падений и по назначению мода.

Два примера, на которых это выяснилось:
- `sodium` роняет сервер **до** загрузки модов: его launch-plugin зовёт
  `org.lwjgl.Version`, а на сервере LWJGL нет вовсе;
- `extrasounds` падает уже в загрузке модов: `Attempted to load class
  net/minecraft/client/gui/screens/Screen for invalid dist
  DEDICATED_SERVER`.

**`appleskin` оставлен на сервере** — у него есть серверная половина,
которая шлёт клиенту насыщение еды.

**RCON включён** (`enable-rcon=true`, порт 25575, пароль в
`server.properties`). Нужен, чтобы гонять `/plague …` из сессии Claude,
не сидя в консоли. Порт слушается на всех интерфейсах — **если
сервер будет открыт наружу, RCON выключить или закрыть фаерволом.**

**`max-tick-time=-1`.** Сторож ваниллы убивает сервер, если тик длится
дольше минуты; на генерации чанков под 87 модами это случается честно
и без причины.

**Ад и Край выключены** (`allow-nether=false`) — по решению проекта
других измерений в сессии нет.

## Порт 25565 и грабля с осиротевшим процессом

Порт штатный — **25565**, тот же, что в паке.

По дороге он дважды был занят, и оба раза одинаково: сервер,
запущенный через `Start-Process`, **переживает собственное падение**.
Проверки версий модов держат живые не-демон потоки, JVM не выходит,
и процесс продолжает держать и порт, и `world/session.lock`.
Следующий запуск падает уже на «часть этого файла заблокирована
другим процессом», и это выглядит совсем другой поломкой.

Лечится тем, что процесс убивается **по командной строке**, а не
по имени `java.exe` — иначе снесёшь заодно чужие gradle-демоны
и дев-серверы соседней сессии:

```powershell
Get-CimInstance Win32_Process -Filter "Name='java.exe'" |
  Where-Object { $_.CommandLine -like '*user_jvm_args.txt*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

Второй раз порт держал дев-сервер `lmpc_classes` из соседней сессии.
Он перевешен на 25567; требование из `lmpc_classes/CLAUDE.md` — держать
дев-сервер не на 25565 — теперь выполнено, но только на этой машине:
`run/` в `.gitignore`, и у следующего, кто клонирует, файла не будет.

## Что делать дальше, по шагам

```
1. start.bat
2. в консоли: op <ник владельца>
3. зайти в игру, встать в понравившемся месте:
     /plague center ~ ~          (сетка 95×95, барьер 1500, спавн)
     /plague center               без аргументов — проверить, куда встало
     /plague center <x> <z> force чтобы передвинуть уже поставленный
4. /plague generate 0.05          посеять 5 % мира
   /plague info                   убедиться, что счётчики поднялись
5. whitelist add … ×8, whitelist on, enforce-whitelist=true
6. раздать пак игрокам (2026-09-05-razdacha-arhivami)
```

Шаг 3 сознательно оставлен человеку: центр мира задаёт, где встанет
Город, а город владелец строит сам.

**Портов два, а не один.** Кроме `25565/TCP` (сама игра) слушается
`24454/UDP` — голосовой чат Simple Voice Chat. Без него голос молчит,
а порча голоса на четвёртой стадии — половина атмосферы подсистемы 2.
Пробрасывать оба.

Наружу ничего не проброшено — это к владельцу и его роутеру. Через
Radmin VPN проброс не нужен вовсе.
