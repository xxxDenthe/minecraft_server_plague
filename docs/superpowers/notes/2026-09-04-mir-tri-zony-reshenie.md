# Мир: решение по трём зонам

**Дата:** 2026-09-04
**Статус:** решение принято, записывается для второй сессии (заражение
игрока сейчас пишется параллельно и этого документа не видит)
**Подсистема:** 4 «Мир» — дизайна раньше не было вообще, это первый кусок

---

## Решение

Мир внутри worldborder (1000 × 1000, см. ядро-спек) делится на три зоны,
у каждой свой способ появления:

```
Город        строится вручную нами двумя (владелец городской спек не
              писал, планировка — задача этой подсистемы)
Пограничье    строения из модов (Dungeons and Taverns и т.п.) ставятся
              автогенерацией, но зона курируется вручную поверх —
              WorldEdit, потому что мир маленький и одноразовый
Гниль         ничего не строим и не курируем. Она растёт сама, это уже
              работает (подсистема 1, закрыта). Полностью заражённые
              чанки (уровень 4, «Ядро», из спека ядра раздел 5) —
              это и есть Гниль как зона. Не заводим для неё
              вотчинный Minecraft-биом: смотри аргументы ниже.
```

## Почему Гниль не становится настоящим биомом

Обсуждалось отдельно. Коротко: смена биома чанка в реальном времени —
не то же самое, что смена блока. Клиент не подхватывает новый биом
(туман, цвет травы, небо) без пересылки чанка заново, а это ровно тот
класс проблем, ради которого спек материализации отказался от
асинхронности («стоит целого класса невоспроизводимых крашей»). Заводить
свой Minecraft-биом означало бы переоткрывать закрытую подсистему 1
(138 тестов) ради выгоды, которую и так дают текущие блоки.

Вместо биома — Гниль остаётся тем, чем уже является: чанками с высоким
`level` в `PlagueGrid`. «Биом» здесь — слово из лора и планировки, а не
термин движка. Если позже понадобится, чтобы сторонний код или моды
спрашивали «заражено ли здесь» — это решается функцией-геттером над
`PlagueGrid`, а не биомом.

## Что это значит для задач

- Город и Пограничье — на нас (владелец мира не давал спека, планировка
  и есть первая задача подсистемы 4)
- Гниль — не трогаем никак, она уже сделана
- Открытый вопрос к владельцу: город наверняка должен сопротивляться
  заражению дольше окружения — в `PlagueState` уже есть `resistanceGrid`
  (0–255 → 0.0–1.0) именно для этого. Вероятно, City-чанкам нужно
  выставить высокое сопротивление через `StartGenerator` при старте
  мира. Уточнить у владельца, когда он освободится от заражения игрока.
