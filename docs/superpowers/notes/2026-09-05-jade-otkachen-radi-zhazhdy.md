# Мод жажды ронял клиент: вырезан его миксин в Jade

**Дата:** 2026-09-05
**Статус:** сделано, проверять в игре
**Относится к:** модпак

## Что было

Клиент падал не при запуске, а через несколько минут игры — когда игрок
наводил прицел на блок с жидкостью (бак, котёл, что угодно из Create):

```
Critical injection failure: Redirector read(Lsnownee/jade/api/fluid/JadeFluidObject;)
in thirst.mixins.json:jade.MixinFluidView from mod thirst
failed injection check, (0/1) succeeded
```

## Причина

`ThirstWasTaken-1.21.1-2.1.5` (сентябрь 2025) дописывает в подсказку Jade
строчку про чистоту воды. Написан под **Jade 15.10.3** (август 2025).
В паке стоит **Jade 15.10.6** (август 2026), где эти внутренности
переделаны, — код жажды туда больше не втыкается и роняет сервер.

Обновить жажду нельзя: 2.1.5 — последняя версия под 1.21.1. Тот же лог
ругался и на другое: `Cold Sweat requires thirst 1.21.1-3.0.0 or higher`.

## Отклонённая попытка: откатить Jade

Первым делом Jade откатили до 15.10.3, а Jade Addons до 6.1.0. **Не
сработало:** запуск сорвался ещё раньше —

```
Unsupported installed optional dependencies:
  Mod ID: 'jade', Requested by: 'kubejsadditions',
  Expected range: '[15.10.5+neoforge,)', Actual version: '15.10.3+neoforge'
```

KubeJS Additions требует Jade не ниже 15.10.5. Откат закрыт.

**Важно про такие ошибки.** Строка «Unsupported installed optional
dependencies» выглядит безобидно, но она валит загрузку модов целиком.
Клиент падает после неё совсем в другом месте — на
`NoClassDefFoundError: customskinloader/fake/itf/IFakeIResourceManager$V1`.
CustomSkinLoader тут ни при чём, это только эхо. Тот же обман случился
и с нашим модом, когда `plaguecore` объявлял зависимость от voicechat
диапазоном `[2.6,)`.

## Что сделано

Из джарника жажды вырезан ровно один миксин:

```
mods/ThirstWasTaken-1.21.1-2.1.5-nojade.jar
    thirst.mixins.json:  убрана строка "jade.MixinFluidView"
    удалён класс dev/ghen/thirst/foundation/mixin/jade/MixinFluidView.class
```

Jade оставлен новым — 15.10.6 и Addons 6.1.1. Всё остальное в жажде
работает: сама механика, фильтр, рецепты, чистота воды в тултипах
предметов. Пропала только строчка про чистоту в подсказке Jade,
когда наводишься на бак.

**Файл переименован с суффиксом `-nojade` намеренно:** чтобы никто не
скачал с Modrinth оригинал и не вернул краш. При обновлении жажды
патч надо накладывать заново — или проверить, не починили ли совместимость.

## Отклонён и третий вариант

Оставить всё как есть и выключить подсказку Jade про жидкости в его
конфиге. В паке с Create эта подсказка слишком полезна.
