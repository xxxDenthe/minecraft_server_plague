# lmpc_gmtools — начало (2026-09-03)

Заводится третий модуль репозитория: `lmpc_gmtools/` — клиентская
админская панель («мастер игры»). Отдельный Gradle-проект, свой
`modId`, свой джарник в паке. Владелец половины — Kuragane (та же
зона, что `launcher/` и раздача пака); `plaguecore/` не трогается.

## Решения

- **Клиентский мод, без серверной части.** Все действия — ванильные
  команды, отправленные `sendCommand` с клиента; право проверяет
  сервер по OP. Это убирает необходимость в сетевом протоколе и
  в согласовании с владельцем `plaguecore`.
- **Пароль `p1dor` — клиентский UX-замок**, не безопасность. Реальный
  барьер — OP на сервере. После первого верного ввода панель и
  быстрые хоткеи разблокированы на сессию клиента.
- **Версия — 1.21.1**, как весь репозиторий (в постановке задачи
  ошибочно значилось 1.20.1, владелец подтвердил 1.21.1).

## v1 (собрано, тесты зелёные)

Хоткей `Insert` → экран с паролем → панель: режим наблюдателя
(с возвратом на прежнее место), `/plague info`, список онлайн-игроков
с телепортом. Хоткей `Home` — быстрый наблюдатель. Подробности —
`lmpc_gmtools/CLAUDE.md`.
