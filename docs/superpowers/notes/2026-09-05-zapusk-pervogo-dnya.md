# Запуск первого игрового дня: что готово и что нужно сделать

**Дата:** 2026-09-05
**Зачем:** владелец хочет начать сессию сегодня. Здесь список того, что
уже работает, и порядок действий до входа игроков.

## Что готово

- **Ядро чумы.** Эпидемия считается, хранится, видна на поверхности
  и под землёй. Баланс — `config/plaguecore-common.toml`.
- **Заражение игрока.** Здоровье, еда, кашель, тусклый экран, порча
  голоса через Simple Voice Chat, отвар, штраф за смерть.
- **Сердце чумы.** Сущность спавнится, разрушается по кускам,
  умирает. Размер — `[heart] scale`, по умолчанию 1.5.
- **Лаунчер.** Раздаёт пак, проверен на стороннем ПК.
- **Панель мастера** (`lmpc_gmtools`) — объявления, вход по паролю.

## Порядок запуска

**1. Поднять сервер.** Его до сих пор нет: заметка
`2026-09-03-pervaya-razdacha.md` заканчивается словами «появится
сервер —». Нужен NeoForge 21.1.249, JDK 21, все моды пака в `mods/`.

**2. Барьер 1000 × 1000.** Отдельного кода нет и не нужно, хватает
ванильной команды с правами оператора:

```
/worldborder center 0 0
/worldborder set 1000
```

Сетка чумы (63 × 63 чанка) рассчитана ровно на этот квадрат.

**3. Посеять эпидемию.** Мир начинается чистым, чума не заводится сама:

```
/plague generate 0.05        # 5 % чанков заражено, очаги случайны
/plague info                 # проверить, что счётчики поднялись
```

Полезное рядом: `/plague night` — прогнать одну ночь вручную,
`/plague pause` и `/plague resume` — заморозить эпидемию,
`/plague setphase <n>` — перескочить на нужную фазу,
`/plague gui` — карта заражения.

**4. Разложить свежие джарники в пак.** Собираются из исходников,
в релиз не качаются:

```
plaguecore/build/libs/plaguecore-0.1.0.jar
lmpc_gmtools/build/libs/lmpc_gmtools-0.17.0.jar
lmpc_shade/build/libs/lmpc_shade-0.8.0.jar
lmpc_classes/build/libs/lmpc_classes-0.5.0.jar
```

Первые три уже лежат в `mods/` свежими (2026-09-05).
`lmpc_classes` в папке всё ещё **0.4.1**, тогда как код 0.5.0 —
собрать и заменить перед раздачей.

**5. Раздать пак.** `tools/publish-pack.js`, порядок — в заметке
`2026-09-03-razdacha-paka-cherez-releases.md`.
