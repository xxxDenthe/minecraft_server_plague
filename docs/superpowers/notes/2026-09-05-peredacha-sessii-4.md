## Состояние

Подсистема 2 доделана целиком. Задачи 1–7 были закрыты в прошлой сессии,
в этой доделаны 8, 9 и 10:

- **8. Тусклый экран.** Пакет `PlagueNetwork.Stage` шлёт клиенту одну
  стадию, `PlagueOverlay` рисует поверх интерфейса чёрную плёнку с
  дыханием по синусу. Плотность: стадия 2 — 0.18, 3 — 0.34, 4 — 0.42.
- **9. `PlagueApi`.** `cure`, `grantImmunity`, `getStage`, `getInfection`,
  `getPermanentLoss` — точка входа для подсистемы классов.
- **10. Голос.** `PlagueVoice` — плагин Simple Voice Chat, портит пакет
  на сервере со стадии 3.

## Одно решение против плана

План велел вставлять `отправитьСтадию` в шесть мест смены стадии
(тик, `задать`, вход, возрождение, кашель, отвар). Вместо этого отправка
живёт одной строкой в конце `PlayerInfection.пересчитатьЗдоровье` —
этот метод и так вызывается всеми шестью. Забыть один вызов теперь
нельзя: экран не может отстать от здоровья.

## Голос: что проверено и чем именно портится

API проверен `javap` по джарнику `voicechat-api-2.6.20`, не по памяти.
Мод в паке — `voicechat-neoforge-1.21.1-2.6.22`, версия API отличается,
2.6.20 — ближайшая доступная в `maven.maxhenkel.de`.

Подключено `compileOnly`, в манифесте `optional`. Дев-сервер поднимается
без голосового чата — проверено, мод грузится как обычно.

Регистрация плагина — аннотацией `@ForgeVoicechatPlugin`, а не файлом
`META-INF/services`, как предполагал план: аннотация есть в API и её
сканирует сам мод.

Обработка на сервере, в потоке голосового чата, на TPS не влияет.
До стадии 3 выходим раньше декодирования — пока никто тяжело не болен,
плагин не делает ничего.

Числа искажения (`PlagueVoice`, стадии 3 и 4):

```
глухота (фильтр НЧ)   0.35 / 0.18     меньше — глуше
хрип (tanh)           1.6  / 3.0
шум по громкости      0.03 / 0.10
дрожь                 нет  / 0.45 на 5.5 Гц
обрыв кадра           нет  / 0.06
```

Понижения тона нет намеренно: кадр обязан остаться ровно 20 мс.

## Открыто

- **Слышимость стадии 4 не проверена на живых людях.** Числа выше —
  прикидка. «Почти неразборчиво» из спека легко превратить
  в «невозможно играть». Крутить массивы в `PlagueVoice`; в конфиг они
  пока не вынесены — вынести, если придётся править на живом сервере.
- **Живые замеры не сняты.** Спек обещает: игрок без брони в чанке
  уровня 4 доходит до стадии 3 за 6–7 минут на поверхности и за 5 минут
  под землёй. Проверить и записать сюда.
- Своя текстура отвара и свой звук кашля ждут владельца.
