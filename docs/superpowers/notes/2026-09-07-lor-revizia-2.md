# Лор переписан: ревизия 2, мистики больше нет

**Дата:** 2026-09-07
**Спек:** `specs/2026-09-05-lor-design.md` — переписан целиком
**Отменяет:** старый лор про бессонных (см. ниже, что именно)

---

## Что случилось

Владелец принёс свой лор целиком, готовым текстом. Он **натуралистический**:
никакого проклятия, никакой мистики. Чуму сделали люди двумя обычными
хозяйственными решениями, и оба на тот момент были разумными.

Старый лор отменён и в игру не идёт.

## Что именно отменено

```
бессонные, девять, что не спали           ← нет
Онисим, последний из них                  ← нет
колыбельная, кормление именами            ← нет
человек с телегой соли, закопанный живым  ← нет
«чума питается забвением»                 ← нет
двести лет                                ← нет
```

## Что теперь

Кратко, подробно — спек, раздел 3.

1. Редкий почвенный гриб жил в местной низине всегда. Безобидная серая
   плесень, только очень нестабильная: колонии сильно разные.
2. **Семь лет назад** управа осушила низину ради пашни. Землю из канав
   развезли по полям — вместе со спорами.
3. **Два года назад** был неурожай. Гнилое зерно, навоз, солому свезли
   в одну яму. Куча грелась, стыла, мокла — жёсткий отбор. Выжила одна
   разновидность: быстрая, живучая, лезущая в корни. Её вывезли на поля
   как перегной.
4. **Эта весна:** мокро, снег сошёл разом, канавы налились водой
   и размыли заражённую землю. Пятна сомкнулись.
5. **Сердце** — колония, сросшаяся из старых очагов в старом дренаже.
   Не дух, не артефакт. Живая ткань, три плотных слоя снаружи.

## Что уцелело — механика, кроме печатей

Руны, угадывание слова вслух в чат, подсказки Летописца, три архива,
триангуляция по трём прямым. **Кода это не коснулось вовсе,**
менялись только тексты и объяснения.

## Хроника и печати отменены тем же днём

Решение владельца, 2026-09-07: счётчика собранного и порога
«набери 24 свидетельства, чтобы бить Сердце» больше нет. В коде их
никогда и не было — только текст в двух спеках, оба поправлены.

Чтение от этого не стало необязательным. Логово нельзя найти,
не собрав три направления из трёх архивов: координат в игре нет,
карта чертится руками. Этого принуждения достаточно, счётчик сверху
добавлял бы только бухгалтерию.

Следствия: `recordSnapshot` остаётся пустым, ветка FTB Quests
под прогресс не нужна, записей стало девять вместо двенадцати
(порог исчез — лишние страницы тоже).

**Тексты записок написаны начисто** и лежат в спеке лора, раздел 9:
пролог, девять архивных записей, восемь бытовых. Тон утверждён
владельцем.


## Новые тайные слова

Старые («бессонн», «онисим», «телег») выкинуты. Теперь шифруется
хозяйственная лексика — её восемь человек между делом не скажут:

```
канав  низин  перегно  неурожа  дренаж
управ  падеж  оттепел  сросл    сажен
```

Правится в `slova.json`, перечитывается по `/reload`.

**Риск, записан в открытые вопросы спека:** «перегной» и «дренаж»
угадать труднее, чем «телега» — это слова из ремесла, а не общие.
Если команда встанет — открывать лупой, а не сидеть.
