### Написана пекарня текстур

`tools/TextureBaker.java` — инструмент разработчика, в джарник мода
не входит. Владелец рисовать не умеет и делает текстуры генератором
картинок; пекарня доводит их до вида, пригодного для Minecraft.

Что делает за один проход: вырезает нужный кусок, ужимает до 16 × 16
усреднением по площади (с весом прозрачности), сшивает противоположные
края, растягивает контраст и подтягивает яркость, сводит палитру
к дюжине цветов, рубит полутона прозрачности по порогу. Рядом кладёт
лист превью: блок крупно и он же три на три, чтобы видеть швы.

Запуск:

```bash
java -Dstdout.encoding=UTF-8 tools/TextureBaker.java \
     --in textures_src --out textures_src/baked \
     --names textures_src/names.txt --seamless
```

Ключ `-Dstdout.encoding=UTF-8` нужен только чтобы русский отчёт
не превращался в кашу в Git Bash.

Полезные ключи: `--crop x,y,ш,в` (вырезать кусок), `--brightness`,
`--colors`, `--alpha auto` (выбить фон), `--alpha-cut`, `--seamless`.
Полный список — в шапке самого файла.

## 3. Решения владельца, принятые в этой сессии

Все три касаются материализации и уже вписаны в её дизайн.

**Первое.** Где помнить, до какой стадии чанк уже отрисован. Решено:
в общей сетке байт рядом с остальными, **не** в данных чанка. Причина:
про незагруженный чанк иначе ничего не узнать, а очередь строить надо
именно из таких.

**Второе.** Асинхронности нет, всё в главном потоке. Причина
подтвердилась фактом при разведке API: блоки чанка лежат
в `PalettedContainer`, у которого стоит `ThreadingDetector` — доступ
из двух потоков роняет игру.

**Третье.** При очистке земля возвращается «по правилу», а не
по памяти: реестра изменённых блоков мы не ведём принципиально.
Гниль станет обычной землёй. Поражённая постройка игрока сама
не восстановится — цена принята осознанно.

**Четвёртое, по текстурам.** Набор блоков будет свой, не переодетая
ваниль. Владелец генерирует картинки, пекарня их доводит.

3. **Регистрация блоков** — `mc/PlagueBlocks` на мод-шине
4. **Файлы ресурсов** — `blockstates`, `models/block`, `models/item`,

   Папки `assets` в моде сейчас нет вообще
5. **`mc/BlockTransforms`** — таблица «было → стало» из спека ядра 8.3
6. **`mc/MaterializationQueue`** — чанки и курсор прогресса, дедуп,

Подземелье — отдельным заходом, после того как поверхность заработает

### Технические опоры (проверены по исходникам NeoForge 21.1.249)

- `ChunkEvent.Load` даёт `ChunkAccess`, а не `LevelChunk`, и может
  прийти **до** статуса `FULL`. Трогать мир прямо в обработчике —
  верный способ повесить загрузку. Обработчик только ставит чанк
  в очередь; работает `ServerTickEvent.Post`. Очередь — требование,
  а не оптимизация
- Флаги замены блока: `Block.UPDATE_CLIENTS | Block.UPDATE_KNOWN_SHAPE`
  (2 | 16 = 18). Соседей не будим, формы не пересчитываем. Дропов
  `setBlock` не создаёт вовсе
- Требования `Properties.setId(...)` в 1.21.1 **нет** — оно появилось
  позже, попытка применить не скомпилируется
- Плёнка на грани — наследник `MultifaceBlock`, шесть булевых свойств
  сторон он заводит сам; **обязательно** переопределить `codec()`
- Высота поверхности — `chunk.getHeight(Heightmap.Types.WORLD_SURFACE,
  x, z)`; метод сам строит карту высот, если её нет, поэтому не звать
  в горячем цикле
- `canSeeSky` есть у `Level`, но **не** у чанка; имея только чанк,
  приближаем сравнением с `MOTION_BLOCKING`
- `@EventBusSubscriber` помечен `@Deprecated` в 1.21.1, но работает
  и уже используется в `NightHook` — стиль не менять

### Чего в проекте нет и придётся заводить

- папки `assets` в ресурсах мода
- генерации данных (`datagen`) в `build.gradle`
- **конфига вообще** — все игровые числа зашиты в Java, хотя по
  правилу проекта баланс должен править текстовый файл
- списка изменённых за ночь чанков: `SpreadEngine.NightResult` отдаёт
  только счётчики, а очереди нужны конкретные чанки

| Файл | Вердикт |
|---|---|
| `TEST_PLAGUE.jpg` | жёлто-зелёная, **основной цвет чумы**, берём |

| три первых файла с травой и камнем | сделаны в 16 × 16 вручную, вышли мутными; перегенерить в 1024 |

Чего не хватает, всё в жёлто-зелёном:

- одиночная свисающая лоза (запрос: `single vertical hanging vine,
  16x16 pixel art, centered, transparent background, flat colors,
  hard pixel edges, no gradients, sickly yellow-green`)
- гнилая земля, обычный куб
- споровый мешок, обычный куб
- нарост на камне — редкими пятнами, чтобы камень просвечивал

Правила для генератора, выведенные на практике: отдавать картинку
**в полном размере** (1024 хорошо), не ужимать самому; в запросе
обязательно `flat colors`, `no gradients`, `hard pixel edges`;
держать один узнаваемый цвет на всю чуму.

Код от текстур не зависит — материализацию можно писать полностью,
подставив временные заглушки, и заменить картинки потом.
