# pack-build собирается из профиля, а не руками

**Дата:** 2026-09-09
**Относится к:** подсистема 7 (лаунчер)
**Опирается на:** `2026-09-08-pervaya-razdacha-arhivami.md`

## Зачем

`launcher/pack-build/` не версионируется, а состав пака целиком есть
только в игровом профиле владельца (`ModrinthApp/profiles/LMPCCHUMA`):
`mods/` репозитория заведомо отстаёт — `mods/MODLIST.md` до сих пор
числит удалёнными Sinytra Connector и forgified-fabric-api, которые
в профиле нужны.

К 2026-09-09 `pack-build/` разошёлся с профилем настолько, что выкладка
из него сломала бы игрокам сборку:

```
                    pack-build   профиль
модов                     107        125
lmpc_classes            0.7.2     0.19.0
plaguecore              0.1.0      0.2.0
lmpc_gmtools           0.18.1     0.19.0
kubejs                      0         10
resourcepacks               0          9
```

## Что сделано

`launcher/tools/build-pack-from-profile.py` — обратное к
`sync-profile.py`: собирает `pack-build/` из профиля.

Берёт `mods` (только `.jar`), `config`, `kubejs`, `resourcepacks`,
`defaultconfigs`, `datapacks`, `shaderpacks`,
`moonlight-global-datapacks`, из `CustomSkinLoader/` — только
`CustomSkinLoader.json` (остальное там кэш скинов, 33 файла).
Поверх профиля накатывается `launcher/pack-config/`: моды с конфигом
в памяти при выходе из игры переписывают файл своим состоянием, и
в профиле лежит уже не эталон. Эталон всегда побеждает.

Не едет: `config/jei/world` (личные закладки по мирам),
`config/obscuria/cache`, `*.log`, `*.bak`, `*.disabled`, `*.tmp`,
`*.old`, `MODLIST.md`, `desktop.ini`, `Thumbs.db`.

**Имена вне ASCII скрипт отвергает до копирования**, перечисляя файлы.
Это та же граница, что в `src/main/archive.js`: `bsdtar` читает список
`-T` в кодировке консоли Windows и на кириллице молча теряет строку.
Именно закладки JEI из папки «Новый мир» уронили первую выкладку.

Проверка встроена в скрипт: после копирования он сверяет размер
каждого файла с исходником и падает на расхождении.

Первый прогон 2026-09-09: 690 файлов — 125 модов (425.6 МБ),
545 конфигов (7.4 МБ), 10 файлов kubejs, 9 ресурспаков (12.6 МБ),
`CustomSkinLoader.json`.

## Что было неверно написано в README

`launcher/pack-config/README.md` предлагал выкладывать пак с ключом
`--managed mods,CustomSkinLoader`. Это не «добавить CustomSkinLoader
к остальному»: `--managed` целиком заменяет список по умолчанию
(`publish-pack.js:41`) и определяет, **что вообще едет игрокам**, а не
только что лаунчер потом чистит от лишнего. По этой команде конфиги,
KubeJS и ресурспаки молча остались бы дома. В README теперь полный
список:

```
--managed mods,config,defaultconfigs,kubejs,resourcepacks,shaderpacks,CustomSkinLoader
```

## Решение владельца

Из `config/` берём всё, кроме мусора (~545 файлов, 7.4 МБ), а не только
шесть эталонных. Причина: у игроков должна быть ровно та настройка
модов, что у владельца, — иначе Create, Coldsweat, звук и прочее
разъезжаются. Варианты «без axiom и worldedit» и «только эталонные
шесть» отклонены.

## Осталось

Выкладка не запускалась: токена в дереве нет и старый отозван.
Команда — в `launcher/pack-config/README.md`. Заодно уедет стартовый
экран, который до сих пор в паке не был.
