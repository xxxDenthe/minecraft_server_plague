# Графический мод трогает рендер неба

**Дата:** 2026-09-04
**Кому важно:** напарнику — подсистема «Мир», цикл суток

## Что

Клиентский графический мод `lmpc_shade` (владелец — Kuragane, отдельный
джарник в паке, `mods/MODLIST.md`) с версии 0.4.0 подменяет
`DimensionSpecialEffects` Верхнего мира через
`RegisterDimensionSpecialEffectsEvent`:

- `SkyType.NONE` — не рисуется небесный купол, солнце, луна, звёзды;
  сверху ровный серый цвет тумана. Пасмурь под лор заражения.
- Рассветные/закатные цвета отключены.
- Высота облаков — в конфиге (по умолчанию ванильные 192).
- **`adjustLightmapColors` (0.5.0): мод правит сам lightmap** — ночью
  затемняет поверхность, освещённую небом и не освещённую блоками, до
  `surfaceNightFloor` (по умолчанию 10% яркости). Цель — «без факела
  ночью на поверхности не видно ничего». Это уже влияет на геймплей
  (видимость мобов), не только на картинку.

Ход времени и `getSkyDarken` мод **не меняет**, только читает. Но
`adjustLightmapColors` — это модификация освещения по времени суток,
она наложится на любую твою логику дня/ночи. Если делаешь свой цикл
суток или своё управление яркостью — скажи, разведём (у мода есть
`nightBoost = 0`, чтобы полностью убрать ночное затемнение).

## Обновление 2026-09-04: серверная синхронизация (0.7.0)

`lmpc_shade` стал `side = BOTH`. На сервере — `SavedData` с мастер-значениями
цветокора и команда `/lmpcshade set|reset` (право 2), рассылка всем при
входе и изменении. Мастер игры правит картину у всех через панель
`lmpc_gmtools`. Джар нужен и в `mods/` сервера.

Серверная логика — только хранение строк и рассылка, никакой обработки
мира. Пересечений с твоими подсистемами это не добавляет; отдельная
серверная команда `/lmpcshade`, своё дерево.

## Зачем записано

Если в подсистеме «Мир» будет своя работа с небом или освещением
(кастомный цикл суток, затмение у Сердца, свой скайбокс) — она наложится
на эту подмену. Тогда:

- либо мод отдаёт рендер неба обратно (в конфиге `[sky] overcast = false`),
- либо согласуем, кто владеет `DimensionSpecialEffects` овервода.

Пока делаю на стороне графмода. Отменю по твоему слову.

## Крутилки (`config/lmpc_shade-client.toml`)

```
[sky]    overcast (true), cloudHeight (192)   — при перезаходе в мир
[light]  nightBoost (1.6), surfaceNightFloor (0.10)   — на лету
```
