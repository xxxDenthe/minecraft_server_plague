Владелец прислал оба токена GitHub (`Contents: Read and write`
и `Contents: Read`) открытым текстом прямо в чат сессии 2026-09-08.
Они попали в транскрипт.

**Why:** токеном на запись можно стереть релиз с паком целиком.
Токен на чтение вдобавок уезжает внутри `.exe` к восьми игрокам,
и достать его оттуда может любой из них.

**How to apply:** после игровой сессии напомнить отозвать оба
и выпустить новые. Новый токен на чтение прописывается командой
`npm run configure -- --repo ... --tag pack --token ...`, после чего
установщик надо пересобрать (`npm run dist`) и раздать заново.
Новый токен на запись достаточно вписать в `launcher/publish.json`.

Сам репозиторий публичный, так что утечка токена на чтение не
открывает ничего, что и так не открыто, — но токен на запись опасен.
