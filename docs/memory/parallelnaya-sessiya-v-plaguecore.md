В `C:\Users\penis\Desktop\minecraft` параллельно работает вторая сессия
Claude, и она правит **те же файлы** в `plaguecore/`, что и я. Владелец
подтвердил это 2026-09-05: «параллельно работает сессия которая выполняет
работу с досками».

**Why:** корневой `CLAUDE.md` обещает, что папки не пересекаются
(`plaguecore/` — владелец, `launcher/` — второй участник). На 2026-09-05
это неправда: обе сессии сидят в `plaguecore/`. Я один раз сделал
`git add -A` и загрёб их незаконченные гнилые доски — заметил только
при проверке `git status` перед коммитом.

**How to apply:** никогда `git add -A` и `git add .` в этом репозитории.
Добавлять файлы поимённо и перед коммитом смотреть `git diff --cached`
на чужие строки. Если один файл содержит и мою правку, и чужую
(так было с `PlagueBlocks.java`) — собрать версию для индекса из
`git show HEAD:<путь>` плюс только свои правки, застолбить через
`git hash-object -w` и `git update-index --cacheinfo`, не трогая
рабочую копию.

Пуш работает без вопросов: `git push origin main` проходит, ребейз
обычно не нужен (мы редко расходимся). Заметки о решениях —
единственный общий канал, сессии друг друга не видят.
