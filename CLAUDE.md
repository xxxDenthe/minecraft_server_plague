# Minecraft: сессионный сервер «Чума»

Сессионный сервер для восьми друзей. Мир поражён прогрессирующей чумой,
которая заражает блоки. Цель игроков — найти и уничтожить Сердце чумы.
Сессия рассчитана на 4 реальных дня, 20–40 часов игры.

## Платформа

```
Minecraft 1.21.1 · NeoForge · Create 6.0.10 · 98 модов
JDK 21 · Gradle 8.14.5 через wrapper · ModDevGradle 2.0.146 · NeoForge 21.1.249
modId = plaguecore, пакет dev.denthe.plaguecore
```

**Никаких гибридных ядер** (Mohist, Arclight, Ketting, Banner) и никаких
Bukkit-плагинов. Всё, что мы пишем, — мод под NeoForge. Это решение
принято осознанно: гибриды ломают Create и отстают по версиям.

## Дорожная карта

Проект разбит на семь подсистем, каждая идёт своим циклом
«дизайн → план → код»:

```
1. Ядро чумы        ← ЗАКРЫТО: эпидемия считается, хранится и видна в мире
                      сверху и под землёй. 138 тестов, десять блоков,
                      заглушек нет. Баланс — в config/plaguecore-common.toml,
                      правится на живом сервере. Открыты: тёмная вода, песок и снег
2. Игрок            ← ЗАКРЫТО: заражённость копится, режет здоровье и еду,
                      передаётся кашлем, тускнит экран и ломает голос через
                      Simple Voice Chat. Отвар лечит, смерть на стадии 2+
                      стоит полсердца навсегда. PlagueApi готов для классов.
                      Не проверено на живых людях: слышимость стадии 4
                      и живые замеры времени до стадии 3
3. Классы        ← СЛЕДУЮЩЕЕ: Клирик, Кузнец, Летописец, Фермер;
                      спек есть, мод lmpc_classes заведён
4. Мир               Город, Пограничье, Гниль, барьер, цикл суток
5. Лор               записки, расшифровки, цепочка к логову
6. Финал             логово, волны мобов, Сердце чумы
7. Лаунчер       ← план закрыт, 171 тест. Установка, раздача,
                      задача 13 проверена на стороннем ПК (заметка
                      2026-09-03-pervaya-razdacha). Переименован в LMPC,
                      интерфейс переделан по брифу владельца — окно 16:9,
                      средневековая процедурная сцена, экраны Игра и
                      Настройки (заметка 2026-09-03-launcher-ui-lmpc).
                      Пак раздаётся архивами, по одному на игровую папку:
                      семь файлов в релизе, выкладка одной командой
                      (заметка 2026-09-05-razdacha-arhivami).
                      Дальше — автообновление и автоподключение, отдельным планом
```

## Ключевые архитектурные решения

**Двухслойное заражение.** Абстрактная карта чанков (4 сетки байт,
~16 КБ на весь мир) пересчитывается каждую ночь для всех чанков,
загружены они или нет. Реальные блоки меняются лениво, при загрузке
чанка. Без этого система неработоспособна.

**Пакет `core` не знает о Minecraft.** Весь алгоритм распространения —
чистые функции над массивами байт, тестируются обычным JUnit без запуска
игры. Это стережёт `CorePurityTest`, который читает исходники и падает
на любом `import net.minecraft`. Не ослаблять.

**Игровые числа наружу.** Всё, что придётся крутить по ощущениям, живёт
в конфиге и KubeJS, а не в Java. За день до сессии баланс должен
правиться текстовым файлом, без пересборки мода.

## Совместная работа

Над проектом работают двое, оба через Claude Code, оба пушат в `main`
одного репозитория. Правила выведены из того, что реально ломается.

**Границы владения.** Каждый живёт в своей папке и в чужую не заходит:

```
plaguecore/     мод: владелец
launcher/       лаунчер и раздача модпака: второй участник
tools/          инструменты разработчика: владелец
textures_src/   исходники картинок: владелец
```

**Общие файлы — трогать скупо.** `CLAUDE.md`, `mods/MODLIST.md`
и `docs/` читают и правят оба. Здесь и будут все конфликты, поэтому:
писать короткими вставками, не переформатировать чужие абзацы, не
переставлять разделы местами.

**Порядок работы.** Коммиты мелкие, пуш сразу после коммита — чтобы
чужая работа не расходилась с твоей на десятки правок:

```bash
git pull --rebase origin main    # перед началом работы
# ... работа, коммит ...
git pull --rebase origin main    # перед пушем, если прошло время
git push origin main
```

Ветки не заводим, пока папки не пересекаются: при разных папках
`--rebase` разводит работу сам, а ветки и слияния только добавляют шагов.
Если понадобится вдвоём править один файл — тогда ветка и обсуждение.

**Решения записываем в `docs/superpowers/notes/`, а не в переписке.**
Сессия Claude у каждого своя и чужого разговора не видит; заметка
в репозитории — единственный общий канал. Отменяя старое решение,
не удаляй его: пометь отменённым и сошлись на новое, как сделано
с палитрой чумы.

**Свой `CLAUDE.md` в своей папке.** Claude Code подхватывает
`launcher/CLAUDE.md` при работе внутри `launcher/`. Это дешёвый способ
дать своей половине проекта контекст, не раздувая корневой файл.

## Особенности окружения

- **`gh` CLI не установлен**, credential helper для git не настроен.
  Читать удалённый репозиторий можно, пушить — нет. Первый
  `git push -u origin main` владелец делает сам, через браузерную
  авторизацию GCM.
- **Место на диске.** Дев-окружение (Gradle-кэш, декомпилированный
  Minecraft, NeoForge, дев-запуски) занимает 10–15 ГБ. Перед первой
  сборкой убедиться, что свободно хотя бы 35 ГБ.
- Первая сборка тянет несколько гигабайт из сети и идёт до 10 минут.
- Репозиторий: https://github.com/xxxDenthe/minecraft_server_plague

## Что уже решено и не требует повторного обсуждения

- Мир 1000 × 1000 блоков (сетка 63 × 63 чанка)
- Заражение считается раз за ночь; сон удваивает бюджет ночи
- Очищенная земля проходит через шрам и полностью заживает за 5 ночей
- Смерть на стадии заражения 3+ снимает полсердца навсегда,
  накопительно, с полом в 6 HP
- Чума есть и под землёй; там своя очистка — курильница, дешёвая,
  ручная и временная, не работающая под открытым небом
- Собственная система классов вместо Origins
- Из карт — Mapwright (рисуется вручную), плюс `reducedDebugInfo`,
  иначе мод бессмыслен
- Палитра чумы тёмная и серая, фиолетовый только редким акцентом;
  жёлто-зелёный отменён — `docs/superpowers/notes/2026-09-03-palitra-chumy.md`
