# lmpc_gmtools — панель мастера игры

Третий мод репозитория (после `plaguecore` и лаунчера). Отдельный
Gradle-проект, свой `modId = lmpc_gmtools`, свой джарник в паке.
Владелец этой половины — Kuragane (как и `launcher/` и раздача пака).

## Что это

Клиентская админская тулза: открывается по хоткею, просит пароль
`p1dor`, после чего даёт быстрый доступ к режиму наблюдателя, телепорту
к игрокам и команде `/plague info` из `plaguecore`.

## Устройство

- **Почти всё — ванильные команды.** Панель шлёт `/gamemode`, `/tp`,
  `/effect`, `/gamerule`, `/title`, `/tellraw`, `/playsound`, `/tick`,
  `/plague` через `ClientPacketListener.sendCommand`; право проверяет
  сервер по OP. Пароль в GUI — только UX-замок от случайного открытия.
- **С 0.8.0 есть серверная часть** — пакет `dev.denthe.gmtools.net`.
  `@Mod` без `dist`, зависимости `side = "BOTH"`. **Jar нужен и в
  `mods/` сервера, версии клиента и сервера должны совпадать.**
  `GmServerBroadcast` раз в 20 тиков шлёт `GmNetwork.Positions` каждому
  OP. Все команды — одно дерево `/gmtools` в `GmCommands`
  (freeze/frozen/ghost/inv/mark/unmark/log), под правом 2. Фичи:
  `GmFreeze` (пин позиции в `PlayerTickEvent`), `GmGhost`,
  `GmInventory` (снимок 41 слота → `GmNetwork.Inventory`),
  `GmMarkers` (`GmNetwork.Marks`, список в памяти),
  `GmLog` (`CommandEvent` → кольцевой буфер). Регистрация пакетов —
  паттерн plaguecore (лямбды на `GmMapClientAccess`, на сервере не
  выполняются). `GmNetwork` VERSION = "3".
- **Наблюдатель туда-обратно** (`SpectatorToggle`): при входе клиент
  запоминает режим и позицию в статике, при возврате шлёт
  `gamemode <прежний>` и `tp @s <коорд>`. `Locale.ROOT` в форматировании
  координат обязателен — русская локаль иначе ставит запятую.
- Хоткеи: `Insert` — панель, `Home` — быстрый наблюдатель (оба
  переназначаются в настройках управления). Пока пароль не введён ни
  разу за сессию, `Home` тоже ведёт на экран пароля.

## Платформа

Та же, что у всего репозитория: MC 1.21.1, NeoForge 21.1.249, JDK 21,
ModDevGradle 2.0.146, Gradle 8.14.5 через wrapper. Пакет
`dev.denthe.gmtools`.

Сборка: `GRADLE_USER_HOME` и JDK 21 уже настроены в окружении
(`D:\dev-cache\gradle\gradle.properties` → `org.gradle.java.home=D:/JDK21`),
достаточно `./gradlew build`. Джарник — `build/libs/lmpc_gmtools-0.1.0.jar`.

## Что сделано

Хоткей + отдельное окно пароля (ввод маскируется). Панель ~452×292 по
центру: слева колонка разделов, у раздела «Мир» сверху ряд папок,
справа содержимое. Кнопки 14–15 px, длинный текст переносится,
опасные действия (убить, бан, телепорт игрока к игроку) просят второй
клик в течение 3 с.

- **Себе** — наблюдатель; режим-призрак (`/gmtools ghost`); «ночное
  зрение» через клиентскую яркость (`Fullbright`, рефлексия поля
  `OptionInstance`, не зелье — частицы выдали бы GM).
- **Игроки** — спокойный список (голова, ник, тонкая полоса HP,
  дистанция); клик → карточка игрока на всю ширину: выдать предмет /
  наблюдать / телепорт к нему / призвать / инвентарь / заморозить /
  телепорт к другому игроку / лечить-кормить / снять эффекты /
  кик-бан-убить. Бан и убить — с подтверждением.
- **Карта** — все онлайн-игроки (головы + ник) и общие метки (иконкой
  предмета) на фоне рельефа прогруженных чанков; тянется мышью, зум
  колёсиком; ПКМ — окно новой метки (иконка + имя), ЛКМ по метке
  убирает. Данные с сервера.
- **Мир** — папки «Погода» и «Правила» (10 правил `/gamerule`, две
  кнопки вкл/выкл — состояние клиенту недоступно).
- **Вещание** — папки «Заголовок» / «Чат» / «Звук»
  (`BroadcastEditorScreen`, `SoundPickerScreen`).
- **Чума** — папки «Общее» (`/plague info`, `/plague gui`) и «Голос»
  (редактор голоса больного из `plaguecore`: два столбца ползунков по
  стадиям + общие «Частота дрожи» и «С какой стадии портить»).
  Мост — `VoiceAccess` через рефлексию
  `dev.denthe.plaguecore.client.PlagueVoiceApi`; жёсткой зависимости
  между джарами нет, нет мода — заглушка. Голос считается **на сервере**,
  поэтому локального превью нет: на отпускании ползунка уходит
  `/plague voice set <ручка> <число>`, сервер меняет звук сразу и пишет
  в свой `plaguecore-common.toml`. Текущие числа спрашиваются
  `/plague voice sync` (при входе в папку и кнопкой «Спросить сервер»).
- **Графика** — редактор цветокора мода `lmpc_shade`. Папки
  Кадр / Ночь / Туман / Небо, в каждой ползунки (`ShadeSlider`),
  hex-цвета тремя ползунками RGB (`HexChannelSlider`), тумблеры. Мост —
  `ShadeAccess` через рефлексию `dev.denthe.shade.ShadeApi` (жёсткой
  зависимости между джарами нет; нет мода — заглушка).
  - **На сервере** (0.16.0) правки уходят командой `/lmpcshade set …`
    (`pushShade`, на отпускании ползунка / клике тумблера) → сервер
    хранит их в мире и рассылает **всем игрокам**. «Вернуть подобранные»
    шлёт `/lmpcshade reset`. Во время перетаскивания — локальный превью
    (`applyValue`), сервер потом присылает то же авторитетно.
  - «Сохранить локально» — только личный `config/lmpc_shade-client.toml`
    (на сервере авторитетно `SavedData`, оно само персистится).
  - Параметры с `*` (небо) применяются после перезахода в мир.
  - Правки стрелками клавиатуры на ползунке на сервер не уходят до
    следующего перетаскивания — мелочь.
- **Опыты** — стоп-кадр мира и «Пауза сессии» (`tick freeze` +
  `plague pause`), всё по двойному клику.
- **Журнал** — `/gmtools log` в чат: последние команды операторов.

Всё рисуется вручную в `GmPanelScreen` (плюс `Fullbright`); палитра
тёмно-каменная, акцент `#7C97A6`. 2 теста на `SpectatorToggle`.

## Версии

Каждое весомое изменение (фича или важное исправление) поднимает
`mod_version` в `gradle.properties`: `0.МИНОР.0` — фичи,
`0.МИНОР.ПАТЧ` — исправления. Свежий jar кладётся в `../mods/`
(старый оттуда удаляется), в репозиторий джарник не идёт.

- **0.17.0** — папка «Голос» в разделе «Чума»: живой редактор голоса
  больного из `plaguecore`. Дюжина ползунков (`VoiceSlider`), мост
  `VoiceAccess` рефлексией на `PlagueVoiceApi`. Правки уходят командой
  `/plague voice set`, значения приходят пакетом после
  `/plague voice sync` — голос портится на сервере, и клиентские числа
  ему не указ. Раздел «Чума» получил папки, старые кнопки — в «Общее».
- **0.16.0** — «Графика» синхронизируется через сервер: ползунки/тумблеры
  шлют `/lmpcshade set …` (`pushShade`), «Вернуть подобранные» — `reset`.
  На сервере цветокор меняется у всех игроков. Ползунки стали
  нестатическими ради `onRelease` (шлём на отпускании, не спамим при
  перетаскивании). Кнопка переименована в «Сохранить локально».
- **0.15.1** — в «Графике» кнопка «Вернуть подобранные»
  (`ShadeAccess.resetAll` → `ShadeApi.resetAll`) — сброс всех параметров
  к дефолтам. Подсказка перенесена выше кнопок (налазила на «Сохранить»).
- **0.15.0** — раздел «Графика»: живой редактор цветокора `lmpc_shade`
  (папки Кадр/Ночь/Туман/Небо, `ShadeSlider` + `HexChannelSlider` +
  тумблеры, «Сохранить в файл»). Мост `ShadeAccess` — рефлексия
  `dev.denthe.shade.ShadeApi`, без зависимости между джарами. Виджеты —
  ванильные `AbstractSliderButton`/`Button`, поэтому мышь/рендер даёт
  `Screen` сам, свой код в `mouseClicked` не нужен.
- **0.14.0** — метки ставятся ПКМ по карте: открывается `MarkerDialogScreen`
  (сетка иконок `MarkerIcons` из 16 предметов + поле имени), координаты
  берутся из точки клика (`screenToWorld`). `GmNetwork.Mark` получил
  `byte icon`, команда стала `/gmtools mark <x> <z> <icon> <имя>`,
  VERSION → "4". На карте метки рисуются иконкой предмета. Поле имени
  и кнопка «Метка здесь» с карты убраны.
- **0.13.0** — четыре самописные функции разом + переделка списка
  игроков (спокойный список: голова, ник, тонкая полоса HP, дистанция).
  Команды свёрнуты в один `/gmtools` (`net/GmCommands`).
  · **Просмотр инвентаря** (`GmInventory` + `GmNetwork.Inventory` +
  `InventoryViewScreen`): `/gmtools inv <игрок>` шлёт оператору снимок
  41 слота, экран показывает их только для чтения, кнопка «Очистить».
  · **Режим-призрак** (`GmGhost`): `/gmtools ghost` — невидимость без
  частиц, неуязвимость, скрытие из tab (`ClientboundPlayerInfoRemovePacket`),
  беззвучность. Шаги всё равно слышно — чисто клиентский звук.
  · **Общие метки** (`GmMarkers` + `GmNetwork.Marks`): `/gmtools mark
  <имя>` / `unmark <имя>`, список в памяти, рассылка операторам и при
  входе; на карте — поле имени + «Метка здесь», клик по метке убирает.
  · **Журнал GM** (`GmLog`): `CommandEvent` пишет команды операторов
  в кольцевой буфер на 100, раздел «Журнал» → `/gmtools log` в чат.
- **0.12.0** — заморозка одного игрока (`net/GmFreeze`): команда
  `/gmtools freeze <игрок>` (переключатель, только оператору) +
  `PlayerTickEvent.Post` возвращает замороженного в точку заморозки и
  гасит импульс. Кнопка «Заморозить / разморозить» в карточке игрока.
- **0.11.0** — раздел «Игроки» переделан: таблица с выравниванием
  чисел вправо, чередованием строк, полосой HP; карточка игрока
  теперь на всю ширину (ряды по 4/3 кнопки через `buttonRow`), без
  узкого списка — назад по «◀ Таблица», к другому игроку выбирается
  в самой таблице. Оптимизация фона карты: `MapTerrainCache` собирает
  слитые по горизонтали прямоугольники и кэширует их — пока вид не
  двигается, отрисовка без обхода клеток. «Пауза сессии» в «Опытах»
  (`tick freeze` + `plague pause` одной кнопкой).
- **0.10.0** — живая таблица игроков в разделе «Игроки»: по умолчанию
  вместо узкого списка — таблица ник / HP (полоса+число) / еда / режим /
  расстояние от GM, клик по строке открывает карточку, в карточке
  кнопка «◀ Таблица». Пакет `GmNetwork.Positions` расширен (health,
  food, mode), VERSION → "2". Стадии заражения нет — подсистема
  «Игрок» в plaguecore ещё не спроектирована.
- **0.9.0** — фон карты: рельеф прогруженных чанков цветами карты-
  предмета (`MapTerrainCache` — выборка верхнего блока по колонке,
  кэш по чанку TTL 5 с, лимит пересчётов на кадр, шаг выборки от зума).
  Ада и Края в игре не будет — фильтр по измерению убран.
- **0.8.0** — раздел «Карта»: серверная часть (`net/`) раз в секунду
  шлёт OP-игрокам позиции всех онлайн; клиентская карта в панели
  (`renderMap`) — свободное перетаскивание (`mouseDragged`), зум к
  курсору (`mouseScrolled`), головы игроков `PlayerFaceRenderer`,
  ник по наведению, сетка через 100 блоков, оси 0/0, кнопка «К себе».
  Игроки других измерений считаются отдельно. Мод стал `side = BOTH`.
- **0.7.0** — редактор `/title`: переразмечен (поля позиций считаются
  в `init`, `styleY/colorY/prevY`), надписи не наезжают. Все кнопки
  раздела «Опыты» теперь через подтверждение (второй клик).
- **0.6.0** — раздел «Вещание» (папки Заголовок / Чат / Звук).
  `BroadcastEditorScreen` — редактор `/title` и `/tellraw`: поле(я)
  текста, 16 цветов, 5 тумблеров начертания, живой предпросмотр; JSON
  для команды собирается вручную с экранированием (сериализатор
  компонентов тянет реестры — не нужен). `SoundPickerScreen` — список
  звуков (`BuiltInRegistries.SOUND_EVENT`), поиск, слайдеры громкости
  и тона, цель «Все» или конкретный игрок, «Стоп всем»; команда
  `execute at <T> run playsound … <T> ~ ~ ~` — звук из точки самого
  игрока. Черновики заголовка и чата переживают закрытие экрана.
- **0.5.0** — выдача предметов: `ItemGiveScreen` — свой список
  предметов вместо JEI (реестр `BuiltInRegistries.ITEM` целиком на
  клиенте: поиск по имени и id, сетка иконок с прокруткой, тултипы,
  слайдер количества 1–64). Кнопка «Выдать предмет…» в карточке
  игрока → `/give`. Каталог строится один раз в статике.
- **0.4.0** — разделы Себе / Игроки / Мир / Чума / Опыты, у «Мира»
  папки. Ночное зрение (яркость, не зелье). Карточка игрока: лечить,
  кормить, снять эффекты, кик, бан, убить (с подтверждением), телепорт
  к другому игроку. Мир: погода, тумблеры gamerule. Опыты: стоп-кадр.
- **0.3.0** — возврат в панель по Esc из `/plague gui` (экран plaguecore
  не знает про нас, возврат ловит `GmClientEvents` по имени класса).
  Длинный текст в разделах переносится по ширине (`drawWrapped`) —
  надписи больше не вылезают за окно.
- **0.2.0** — панель на пол-экрана, разделы Действия / Игроки / Чума,
  игроки вынесены в отдельный раздел с прокруткой и карточкой игрока,
  маскировка пароля. Починены наслаивающиеся надписи.
- **0.1.0** — первая версия: хоткей, пароль, наблюдатель, `/plague info`,
  плоский список телепорта.

## Дальше

- Весь список «строить самим» собран (0.10–0.13): живая таблица
  игроков (без стадии заражения — её в `plaguecore` ещё нет),
  заморозка игрока, пауза сессии, просмотр инвентаря, режим-призрак,
  общие метки на карте, журнал GM. Дальше — по запросу владельца.
- Возможные доработки: инвентарь сделать редактируемым; метки в
  SavedData вместо памяти; журнал GM в файл; стадия заражения в
  таблицу и на карту, когда появится подсистема «Игрок».
- **Время суток не трогаем** — будет своя система дня/ночи, ванильное
  `/time` её сломает. Сложность и мировая граница ставит сервер.
- **Ада и Края в игре не будет** — не закладываться на другие измерения.
